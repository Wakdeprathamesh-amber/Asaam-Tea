# Asaam-Tea

Premium e-commerce experience for Assam Tea — cinematic scroll-scrub hero, GSAP storytelling, and product collection.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Regenerate hero frames

After updating `public/tea-story-desktop.mp4`:

```bash
npm run generate:frames
```

## Deploy

Configured for [Vercel](https://vercel.com) via `vercel.json` (Node server + static assets).
